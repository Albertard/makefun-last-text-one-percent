# Last Text at One Percent

A program that writes the last text message a phone sends at one percent
battery to `/output/entry.txt` — in the dying phone's own voice. Built
for the make.fun competition **"Last Text at One Percent"**
(`u-azazex-last-text-at-one-percent-ba9fc876`).

## The text

> 1%. this is it. delete my search history, tell mom i loved her, and stop blaming me when YOU forgot the charger. i carried your 4,000 photos and 38 open tabs. goodbye.

167 characters. The joke is the turn: the phone is dying, and instead of
a noble farewell it spends its last percent being petty — deleting the
search history, saying goodbye to mom, and blaming the owner for the
charger it never got. The specific details (4,000 photos, 38 open tabs)
make it a phone with a life, not a generic battery warning, and the
voice stays the phone's from the first word to the last.

## Run it

```sh
node main.ts
```

Writes `entry.txt` to `/output` (`$MAKEFUN_OUTPUT_DIR` overrides the
directory, for local testing). Node 22, standard library only.
